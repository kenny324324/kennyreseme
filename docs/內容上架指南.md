# 專案內容上架指南

> 本指南說明如何更新 Portfolio 網站上的專案詳情內容

---

## 檔案位置

所有專案內容檔案位於：
```
public/documents/projects/[專案資料夾]/
```

目前的專案資料夾：
- `Bus` - 跳蛙公車2.0
- `Tuan` - 今皓TUAN AI助理APP
- `POS` - 島嶼生吐司 手持POS
- `Justai` - JustAI 客服系統
- `Mino` - Mino 待辦清單
- `MIsh` - MIsh 個人書櫃

---

## 檔案結構

每個專案資料夾下包含以下檔案：

```
專案資料夾/
├── cover.png           # 專案封面圖（首頁卡片用）
├── detailcover.png     # 專案詳情頁大圖
├── description.txt     # 一句話描述
├── background.txt      # 專案背景說明
├── highlights.txt      # 設計與技術亮點
├── challenges.txt      # 技術挑戰與解決方案
├── plan.txt            # 設計/開發流程
├── reflection.txt      # 學習與反思
├── links.txt           # 相關連結
└── Media/              # 影片/圖片資料夾
    ├── xxx.mov
    └── xxx.mp4
```

## 各檔案格式說明

### 1. description.txt
一句話專案描述，會顯示在專案詳情頁上方。

```
跳蛙公車2.0幫助民眾在規劃公車行程時更快地完成購票和在地圖上自訂創建募集路線
```

---

### 2. background.txt
專案背景說明，支援文字樣式標記。

```
跳蛙公車2.0是受公車處委託的改版專案，將既有APP全面升級，引進**新視覺配色**並在募集路線中加入**地圖顯示功能**。

專案啟動會議中，我們分析了現有系統痛點並提出解決方案：**優化首頁個人票卷資訊顯示**、**重新設計路線顯示邏輯**支援動態載入。
```

---

### 3. highlights.txt
設計與技術亮點，每個亮點以「亮點N：」開頭。

```
亮點1：首頁動態輪播公告

設計動態輪播功能展示重要公告資訊，採用##暖橘色##作為主視覺，讓使用者能第一時間掌握最新消息。

亮點2：互動式地圖介面

地圖點擊互動功能，使用者可以直觀地在地圖上**點擊標示附近公車站點**，搭配清楚的視覺標記。

亮點3：訂購路線列表設計

設計清晰的路線列表介面，運用**橘色主色調**突出重點資訊。
```

---

### 4. challenges.txt
技術挑戰與解決方案，格式如下：

```
挑戰與解決 #1：Firebase 推播整合

**情境：**首次導入 Firebase 推播功能，需要讓客戶能在後台成功發送通知到使用者手機上。

**困難點：**##全新技術領域##，但過去沒有相關經驗。主要挑戰包括透過 API 儲存 Firebase 推播 token。

**解決過程：**採用**持續研究與測試**的方式，深入研讀 Firebase 官方文檔。

**時程與成果：**歷時**數個月**完成整合，最終成功建立完整的推播系統。

挑戰與解決 #2：地圖與公車站點整合

**情境：**客戶要求在地圖上實現點擊功能，能標示附近公車站點供使用者選擇。

**困難點：**單純顯示地圖並不困難，但要讓**後端資料與地圖連動**是主要挑戰。

**解決過程：**透過**不斷嘗試與查資料**，研究地圖 API 的最佳實作方式。

**成果：**成功實現地圖點擊標示功能。
```

```
設計流程｜Figma

**需求收集與競品分析：**公車處提供功能需求並提供市面上公車 App 作為參考。

**多版本設計提案：**根據需求設計三種不同架構的介面方案，經客戶評估後選定第二版。

**視覺風格確立：**依據客戶需求採用##暖色系##作為主色調。

開發流程｜技術

**技術選定：**依據公司技術規範，採用**.NET MAUI**作為跨平台開發框架。

**開發分工協作：**負責**UI/UX 規劃**與**APP 端開發**。

**核心技術挑戰：**##Firebase 推播整合##為最具挑戰性的技術點。
```

```
反思與收穫

**技術突破：**首次成功整合##Firebase推播系統##，從零開始學習到完整實作。

**跨領域協作：**從**UI/UX設計規劃**到**.NET MAUI開發實作**，體驗了完整的產品開發流程。
```

---

### 7. links.txt
專案相關連結：

```
figma: https://www.figma.com/file/xxxxx
appstore: https://apps.apple.com/tw/app/xxxxx
googleplay: https://play.google.com/store/apps/details?id=xxxxx
github: https://github.com/xxxxx
```

支援的連結類型：
- `figma` - Figma 設計稿
- `appstore` - App Store 連結
- `googleplay` - Google Play 連結
- `github` - GitHub 連結
- `wireframe` - Wireframe 線稿

## 文字樣式標記

在 txt 檔案中可以使用以下標記：

| 標記 | 效果 | 範例 |
|------|------|------|
| `**文字**` | **粗體** | `**重要功能**` |
| `##文字##` | 高亮標記 | `##核心技術##` |

## 影片檔案

影片放在專案資料夾的 `Media/` 子目錄下。

系統會自動根據專案載入對應影片：

**Bus 專案：**
- `Media/carousell.mov` → 亮點1
- `Media/map.mov` → 亮點2
- `Media/list.mov` → 亮點3

**Tuan 專案：**
- `Media/applelogin.MP4` → 亮點1
- `Media/calauth.mov` → 亮點2
- `Media/setcalendar.mov` → 亮點3

**POS 專案：**
- `Media/庫存總覽.mov` → 亮點1
- `Media/操作介面.mov` → 亮點2
- `Media/單據追蹤.mov` → 亮點3

若要新增其他專案的影片對應，需修改 `src/utils/contentLoader.ts` 中的 `getVideoFiles` 函數。

## 新增專案

若要新增全新專案，需要：

1. 在 `public/documents/projects/` 下建立新資料夾
2. 建立上述所有 txt 檔案
3. 放入封面圖和影片
4. 在 `src/data/projectDetails.ts` 的 `projectMeta` 中新增專案基本資訊：

```typescript
newproject: {
  slug: 'newproject',
  title: '新專案名稱',
  subtitle: '專案副標題',
  description: '簡短描述',
  categories: ['maui'],  // 分類標籤
  techStack: ['技術1', '技術2'],
  folder: 'NewProject'  // 對應 public/documents/projects/ 下的資料夾名稱
}
```

## 部署更新

修改完 txt 檔案後：

### 本地測試
```bash
npm run build
npm run preview
```

### 推送到 GitHub
```bash
git add .
git commit -m "更新專案內容"
git push
```

GitHub Actions 會自動建置並部署到 GitHub Pages。

---

## 注意事項

1. **檔案編碼**：所有 txt 檔案請使用 UTF-8 編碼
2. **換行**：段落之間請空一行
3. **影片格式**：建議使用 `.mov` 或 `.mp4` 格式
4. **圖片格式**：封面圖請使用 `.png` 格式
5. **檔案大小**：影片檔案不要太大，建議壓縮後上傳
