反思與收穫

**從「想要的功能」到「做得出來的產品」：**這個專案最大的收穫是驗證了「因為自己想用，所以自己做」的開發動力。從一開始只是想要一個有圖表的 Spotify 統計工具，到最終完成一款功能完整、已上架 App Store 的產品，整個過程讓自己更確信：最好的專案動機來自真實的個人需求。

**平台政策的現實考量：**Spotify 的 Quota Mode 限制是這個專案最大的轉折點。從技術面來說 APP 已經完成，但平台政策的限制讓它無法開放給更多人使用。這個經歷讓我學到，在選擇串接第三方 API 開發產品時，必須在開發初期就充分了解平台的政策與限制，避免投入大量時間後才發現商業模式不可行。

**自製圖表的技術深度：**選擇不使用第三方圖表套件，全部以 SwiftUI 原生繪圖實作，雖然開發時間更長，但對 SwiftUI 的動畫系統、Path 繪圖、狀態管理有了更深入的理解。這些從零打造的經驗，比直接套用現成套件學到的東西多出許多。

**Demo Mode 的審核經驗：**因為 Spotify API 的使用者限制，必須為 App Store 審核設計 Demo Mode，讓審核人員能在不登入 Spotify 的情況下體驗完整功能。這個經驗讓我理解到，上架不只是寫完程式，還需要考慮審核流程中可能遇到的各種情境，提前做好準備才能順利通過。
