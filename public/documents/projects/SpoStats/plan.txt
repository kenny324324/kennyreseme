設計流程｜Figma

**以自身需求驅動設計：**沒有使用 Figma 繪製設計稿，而是以自己作為目標使用者，直接在 Xcode 中邊開發邊調整介面。核心設計理念是「用圖表說話」——相較於市面上同類型 APP 以純數據列表呈現統計資料，刻意將大量的圖表視覺化元素融入各個頁面。

**深色主題與品牌一致性：**整體介面採用深色主題，搭配 Spotify 品牌綠（#1DB954）作為主要強調色，營造與 Spotify 一致的視覺體驗。同時支援使用者自訂主題色彩，讓介面風格可以依個人喜好調整。

**Tab 導航架構：**以四個主要分頁（首頁、搜尋、排行、設定）組織功能，首頁作為儀表板呈現今日聆聽摘要與排名趨勢，排行頁提供三種時間範圍（1 個月／6 個月／全時間）的切換篩選。

開發流程｜技術

**Spotify OAuth 2.0 認證：**實作 OAuth 2.0 搭配 PKCE（Proof Key for Code Exchange）安全認證流程，透過 ASWebAuthenticationSession 開啟 Spotify 授權頁面，取得 Access Token 後安全儲存於 Keychain，並實作自動 Token 刷新機制。

**三層資料架構：**設計 API Response Cache → UserDefaults 本地儲存 → Spotify API 的三層資料策略。啟動時優先讀取快取資料立即呈現，同時在背景非同步更新 API 資料，兼顧啟動速度與資料即時性。可設定自動刷新頻率（預設 5 秒）。

**排名歷史追蹤系統：**透過 RankingHistoryService 以每小時為最小間隔自動記錄 Top 50 排名快照，累積七天歷史資料。搭配 CloudKit 公開資料庫實現跨裝置同步，並自動清理過期資料。

**自製圖表引擎：**使用 SwiftUI Path 繪圖 API 從零打造折線圖與長條圖，實作漸進式繪製動畫（trim modifier）、互動式選取、動態軸線縮放與標籤防重疊等進階功能，完全不依賴第三方圖表套件。
